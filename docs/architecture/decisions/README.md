# Architecture decision records

Use one Markdown file per significant approved decision. Name files with a zero-padded sequence and a short slug, for example `0002-jooq-code-generation-strategy.md`.

Each ADR states its status, context, decision, and consequences. Do not record a proposal as accepted before approval.
