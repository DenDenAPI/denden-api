# Security Policy

## Supported versions

DenDenAPI is currently pre-release. Security fixes are applied only to the latest code on `main`; no released version is supported yet.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/DenDenAPI/denden-api/security/advisories/new) to send the report privately. Include:

- the affected component;
- steps to reproduce or a proof of concept;
- the potential impact;
- any suggested mitigation, if known.

You may expect an initial acknowledgement within seven days. Investigation and remediation times depend on severity and maintainer availability. Please allow a reasonable period for a fix before public disclosure.

If private vulnerability reporting is temporarily unavailable, contact the repository owner through a private contact method listed on their GitHub profile.
